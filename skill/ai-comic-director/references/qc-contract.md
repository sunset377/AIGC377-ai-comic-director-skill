# 质检合同

用于 `episode`、`libtv-prepare`、`review` 和 `full`。质检区分计划、已写入、已运行和已观察，不能用计划文件代替远程证据。

## 文件完整性

项目卡、世界观与季纲、角色连续性档案、分集剧本、分镜表、资产清单、LibTV 节点图和 QC 报告必须齐全。文件名和 ID 一致，引用目标存在，旧版本未被覆盖。

## 剧本与分镜

- 本集欲望、障碍、升级、转折、兑现和延续清楚。
- 时间带从 `0.0` 开始、连续无重叠、末点等于实际时长。
- 每镜叙事任务、起点、动作、终点和摄影机可读。
- 高风险动作有降级方案。

## 连续性与资产

- 所有角色 ID 都能回到唯一权威条目。
- 外观、服装、道具、伤痕、地点、时间、视线和已知信息无未解释跳变。
- 所有正式资产有来源与 `rights_status`；只有 `APPROVED` 资产可进入上传计划。
- 提示词引用的资产、角色和分镜真实存在。

## LibTV

- 模型和参数来自当前 schema，不是历史猜测。
- 节点、入边、资产顺序和提示词已回读。
- 未获得付费授权时没有运行记录，状态为 `READY_FOR_REVIEW` 或 `NOT_RUN`。
- 未执行远程写入时不得标记远程配置通过。

## 状态

- `QCStatus=PASS`：所有本次范围内的必需检查均有证据且通过。
- `QCStatus=BLOCKED`：缺少客户输入、权限、工具、登录、模型或权利证明，当前不能继续。
- `QCStatus=FAIL`：已检查到真实不符合项，需要修复。

QC 报告必须列出证据路径、阻塞项、失败项、未授权动作和未运行的外部操作。没有观察到的项目写 `NOT_RUN`，不写 PASS。
