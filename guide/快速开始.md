# AI 漫剧导演 Skill｜快速开始

## 安装

在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\installer\install.ps1
```

安装器不会覆盖已有版本。升级时使用 `-Upgrade`，旧版本会先移动到备份目录。

## 第一次创作

```text
使用 $ai-comic-director，为我开发一部 9:16 都市悬疑漫剧，共 3 集，每集约 60 秒。先完成项目卡、角色连续性档案、分集剧本、分镜、资产清单和 LibTV 节点计划；不要连接账号，不要上传，不要运行付费生成，完成后停在 READY_FOR_REVIEW。
```

可用模式：

- `develop`：世界观、人物、季纲与分集结构。
- `episode`：一集剧本、分镜、提示词与资产清单。
- `libtv-prepare`：在获得授权后准备 LibTV 画布并回读验证。
- `review`：审查真实生成结果并提出最低成本修复。
- `full`：从立项做到 LibTV 准备，仍不自动进入付费生成。

## 标准导演包

导演包包括 `00_项目卡.md`、`01_世界观与季纲.md`、`02_角色连续性档案.md`、`03_分集剧本.md`、`04_分镜表.md`、`05_资产清单.csv`、`06_LibTV节点图.md` 和 `07_QC报告.md`。

远程未执行时写 `NOT_RUN`。默认安全终点 `READY_FOR_REVIEW` 只代表导演包或画布已准备好，等待用户复核和下一次授权。
